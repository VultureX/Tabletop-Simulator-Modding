Github no longer supports https links so now you need SSH key creation...
https://medium.com/@kyledeguzmanx/quick-step-by-step-guide-to-generating-an-ssh-key-in-github-d3c6f7e185bb

Basically:
 - run 'ssh-keygen -b 4096 -t rsa'
 - press enter on all prompts
 - find the key in C:\Users\[USERNAME]\.ssh\is_rsa.pub
 - Copy + add it in Github account settings under SSH keys
